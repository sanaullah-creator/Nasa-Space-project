# Assets

Mission visuals are generated as SVG by `src/components/missions/MissionArt.tsx`, so no bitmap assets are required.

- Put **imported** assets here (e.g. a logo or fonts that are bundled with `import logo from './assets/logo.svg'`).
- Put **real NASA photos** in `public/images/` and reference them from a mission's `image` field in `src/data/missions.ts` (see the README section "Images & credits").
